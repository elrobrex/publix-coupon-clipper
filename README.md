# Publix Coupon Clipper

A tiny Chrome extension that automatically clips Publix digital coupons because manually clicking hundreds of coupons is absurd.

Created by Rob Rex.

## What it does

- Finds available "Clip coupon" buttons
- Clicks them automatically
- Refreshes the page to load the next coupon batch
- Continues until no coupons remain

Built after discovering that Publix loads coupons in batches and makes users manually clip them one at a time.

## Features

- No external services
- No tracking
- No analytics
- No account access
- Runs entirely in-browser

## Compatibility

Currently supported:

- Desktop Chrome
- Chromium-based desktop browsers

Not currently supported:

- Mobile Chrome
- iPhone/iOS browsers
- Safari

Mobile support may be possible in the future through userscripts or Android browsers with extension support.

## Installation

1. Clone or download this repository
2. Open Chrome and navigate to: chrome://extensions
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select the project folder
6. Visit https://www.publix.com/savings/digital-coupons
7. Click "Clip All Coupons"
